# Hero Not Strong — Көчө мектеби

River City Ransom сыяктуу капталдан көрүнгөн көчө мушташынын нөлдөн жасалган биринчи версиясы. Өзүнүн каармандары жана көчө көрүнүшү бар; башка оюндун сүрөттөрү колдонулган жок.

## Баштоо

`index.html` файлын браузерден ачыңыз. Орнотуу жана интернет талап кылынбайт. «Оюнду баштоо» баскычын басыңыз.

## Башкаруу

| Баскыч | Аракет |
|---|---|
| WASD / жебелер | Көчөдө төрт багытка басуу |
| J | Муштум: 14 урон |
| K | Тепки: 22 урон, алысыраак жетет |
| Space | Секирүү |
| E | Мушташ бүтүп, коопсуз кезде дүкөндү ачуу |
| Esc | Пауза / улантуу |
| Enter | Баштоо / улантуу |

Телефондо экрандык баскычтар бар. «Толук экран» баскычы браузердин толук экран режимин ачат.

## Эмне кошулду

- 3 квартал, душмандардын 3 тобу жана акыркы башчы.
- Каптал боюнча камера, көчөнүн тереңдиги боюнча кыймыл жана секирүү.
- Муштум, тепки, сокку эффекттери, комбо көрсөткүчү жана HP.
- Душмандар каарманга жакындап чабуул коёт. Бийик секирүү айрым соккулардан качууга жардам берет.
- Душмандан түшкөн тыйындар: кадимки душман 20 сом, башчы 60 сом.
- Коопсуз кезде E басып, 20 сомго +40 HP берген самса сатып алуу.
- Квартал тазаланмайынча алдыдагы жол жабык. Акыркы душмандарды жеңип, EXIT белгисине жетсеңиз жеңиш болот.
- Баштоо, пауза, жеңиш, жеңилүү жана кайра ойноо экрандары.
- Бардык графика canvas менен тартылат; тышкы файлдарга же китепканаларга көз каранды эмес.

Бул биринчи ойной турган версия. Үн, сактоо системасы жана кошумча карталар азырынча жок.

## Каармандын спрайты

hero-sprites.png: 512×640 PNG, 64×64 клеткалар, 8 мамыча, 10 катар, 58 кадр. sprite-animations.json катарлар менен кадрлардын санын берет. Сол багыттар оң багыттардан күзгүдөй жасалган. ImageGen сүрөтү Python менен клеткаларга бөлүнүп, nearest-neighbour менен өлчөндү; alpha 0/255, бут baseline 60. sprite-prompt.txt колдонулган ImageGen промптун сактайт. Бул актив даярдалды; оюндагы procedural каарман азырынча сакталган.
