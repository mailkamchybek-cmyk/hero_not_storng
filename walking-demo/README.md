# Walking demo

Ачуу: ушул папкадагы index.html. Интернет жана сервер талап кылынбайт.

Canvas 800×450, ачык боз фон. D/→ оңго, A/← солго. 200 px/сек, 8 FPS, беш кадр Contact → Low → Passing → High → Contact иретинде айланат. Баскыч бошотулганда үчүнчү кадр токтоп туруу үчүн колдонулат (берилген сүрөттө өзүнчө idle жок).

Берилген сүрөт Python менен беш кадрга бөлүнүп, четине туташкан ак фон тазаланды. Ак футболканын ички өңү сакталды. Жалпы масштаб, 128×160 клеткалар жана baseline 151. CSS image-rendering:pixelated жана Canvas imageSmoothingEnabled=false. Каарман Canvas чегинен чыкпайт. Солго басканда горизонталдуу бурулат. requestAnimationFrame, blur жана visibilitychange иштетилген.

Негизги оюн өзгөртүлгөн жок: бул өзүнчө басуу демосу.

## Чуркоо
Shift + A/D же жебелер — RUN: 8 кадр, 12 FPS, 400 px/сек. Shift бошотулса WALK: мурдагы 5 кадр, 8 FPS, 200 px/сек. Баскычтар бошотулса IDLE. Которулганда циклдин салыштырмалуу фазасы сакталат. run.png берилген сүрөттүн оңго чуркаган 8 кадрынан даярдалды; солго горизонталдуу mirror. Экөөнүн клеткасы 128×160, baseline 151, жалпы бийиктиги бирдей. Негизги көчө мушташы өзгөргөн жок.


«Чуркоо» баскычы автоматтык чуркоону күйгүзөт: каарман караган тарабына өзү 400 px/сек менен жүгүрөт. Кайра бассаңыз токтойт. A/D же жебелер багытты өзгөртөт. Терезеден чыкканда автоматтык чуркоо токтойт. Shift менен кол менен чуркоо да сакталат.
